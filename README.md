## ⚡ Download

**macOS (Apple Silicon)** — get the latest build:

👉 **[Download Superpower for Mac](https://github.com/MrWorld/spi.releases/latest)**

1. Open the latest release
2. Download the `.dmg`
3. Drag **Superpower** into Applications
4. Launch and sign in

Updates install automatically in the background. Your projects, chat, and settings stay put.

> Having trouble opening the app the first time? Right-click → **Open**, or allow it in **System Settings → Privacy & Security**.

## ✨ Why Superpower

Most tools split your team across Notion, Figma comments, Slack threads, and a separate IDE. Context dies in the gaps.

**Superpower** is built so product, design, and engineering can live in one place:

- Write the PRD next to the code that implements it
- Turn ideas into tasks the whole team can see
- Chat like Telegram — with task cards, docs, and files in the conversation
- Let an AI agent work *inside* your real project, not a toy sandbox

Built for teams that move fast and still care about craft.

## 🚀 Features

### Product mode
Plan without needing a local repo. Break work into tasks, polish acceptance criteria, keep docs versioned, and ask Product AI for prioritization and clarity.

### Coding workbench
A serious IDE surface: files, search, terminal, git, Monaco editing — plus AI that can read your tree, propose changes, and help you ship.

### Team chat (Telegram-style)
Project groups and DMs, voice notes, voice chat, media preview in-app, @mentions for people / tasks / docs / files, and status-colored task cards in the thread.

### Design system tools
Tokens, components, and a design studio so visual language stays connected to the product — not stuck in a separate tool nobody opens.

### Always up to date
Signed auto-updates from this repo. Install once; stay current without re-downloading manually.

## ❓ FAQ

**Which Macs are supported?**  
Apple Silicon (arm64) macOS builds. Intel support may come later — say so in Issues if you need it.

**Do I lose data when updating?**  
No. Updates install in place; projects and settings remain.

**Is this open source?**  
This repository hosts **public downloads and release notes**. Product development continues in our private source tree; community feedback here still drives what we ship.

**Can my whole company use it?**  
Yes — create a team, invite people, share projects. Start with a small pod, then expand.

**Where do I get help?**  
[GitHub Issues](https://github.com/MrWorld/superpower/issues) is the fastest path.
